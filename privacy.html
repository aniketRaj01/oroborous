Privacy Policy

Last updated: 3 October 2026

Oroborous is a private project in development. This policy describes what it does today, in plain language.

What Oroborous does

Oroborous generates short videos and uploads them to YouTube channels that are owned and operated by its developer. It does this through the YouTube Data API and requests only the youtube.upload scope, which lets it upload videos and nothing else.

Data we handle

  • OAuth refresh token. To upload without asking for sign-in each time, an OAuth refresh token for the developer's own Google account is stored privately. It is used only to upload videos.
  • No viewer data. Oroborous does not collect any data about people who watch, like, comment on or otherwise interact with its videos.
  • Nothing is sold or shared. No data is sold, rented or shared with third parties.

This website

This website has no analytics, no cookies and no trackers, and makes no requests to third-party services. It has no forms. If you choose a light or dark theme, that choice is saved only in your own browser's local storage and never sent anywhere.

YouTube API Services and Google

Oroborous uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Oroborous's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google user data obtained via the API is used only to provide the upload functionality described above. It is not used for advertising and is not transferred to anyone else.

Revoking access

You can revoke Oroborous's access to a Google account at any time at https://myaccount.google.com/permissions. Revoking access invalidates the stored token, and uploads stop.

Third-party accounts

No third-party accounts are connected to Oroborous today. This policy will be updated before any third party's account is ever connected.

Changes

If this policy changes, the date above will change with it.
